# 模型合同和公平比较

到达发生在tick开始，发送占据整个tick预算，记录在tick+1边界完成。所有业务记录先按tick稳定排序，tick相同时保留输入顺序。电路周期固定为users个tick，无动态建链或预留重分配；用户闲置不能把配额送给其他用户。

共享FIFO分组不抢占，不按用户轮询，不重新排列。头部只在准入初始化一次，partial发送保留剩余wire bit。若一个tick发完队首且尚有预算，应继续下一条。电路对自己的队列也采用相同的预算填充规则。

两模型均用总payload预留缓存；完整记录交付后释放其payload空间，已发送但未完成的记录仍占完整原始payload。空间不足整条记录丢弃，即使本tick稍后能发送也不改变先到达后服务的规则。该特殊规则为课堂模型，实际设备可采用其他缓存计量和调度。

有限窗口截至cfg.ticks，不追加排空阶段。按完整业务记录统计交付，因此部分发送的记录全部payload仍归入pending，不能在守恒式中重复计数。wire_sent_bits与payload交付不是相同概念，可能包含头部和未完成记录。

本实验抽象链路128kbit/s，不包含完整E1物理层。PCM辅助示例使用32时隙、8bit、8kHz，保留0和16，空闲码255只作可辨识示例，不代表对所有PCM编码的静音字节。

未建立传播、误码、重传、建链延时或多跳网络，实验不能据此判断实际互联网或电信系统的总体优劣。选做若改变假设，必须在报告中说明。
